# Data Explorer 视觉改版 · 三方向

## 一、Spec（三个方向的共同输入）

- **项目**：Data Explorer（数据探查器），Python 数据分析交互式学习网站。29 个主题 / 125 步，五种画布：图表（SVG）、运行时（代码+变量+控制台）、表格（DataFrame）、模型（散点/树/柱）、3D 场景（three.js）。
- **受众**：自学 Python 数据分析的中文学习者（学生 / 转行者），要"看得懂、跟得住、不劝退"。
- **场景**：桌面端为主，一次学一个主题的一步；三栏工作区（左侧主题目录 / 中央画布+步骤卡 / 右侧主题概览）。
- **核心信息**：① 代码每一步都能在画布上看见结果；② 概念用图讲，不是用字堆；③ 学习进度可追踪。
- **情感基调**：现在是"蓝色工程蓝图"（理性、冷、mono），改版要解决的核心问题是**单调**——大面积的灰白卡面 + 只在按钮上出现的蓝，让中区/右区显得空、平、低对比。
- **输出格式**：1440×900 桌面视图，三版展示**同一屏真实内容**（顶部栏 + 左侧主题目录 + 中央"横向条形图"步骤 + 右侧主题概览），只换设计语言，方便横向对比。
- **已知约束**：站点是 React + Vite，改版只动视觉层（CSS 变量、字体、布局节奏），不动内容结构与画布逻辑。

## 二、六个候选（六张方向卡）

### 卡 1 · 最佳设计师｜Edward Tufte × 吕敬人（书页版心）
- **借的机制**：Tufte 的"数据墨水比"——图表只留数据本身，用细规则线替重边框、去一切 chartjunk；吕敬人的"版心呼吸"——版心不居中、天头小地脚大、旁注栏、朱印只点一处。
- **不借的**：吕敬人的做旧纸张/烫印肌理（HTML 做不到，降级为纯暖纸色）；Tufte 的英文排印。
- **主角素材**：图表本身 + 大号宋体标题（无真图需求，主视觉是数据）。
- **骨架**：三栏改"书页式"——左窄旁注栏（步骤号/笔记）、中央大画布（图表为 hero）、右正文阅读流。
- **胆量**：首页一根去边框的 sparkline 长卷当视觉主线。
- **form 来自内容**：这是教人"读图"的站，UI 自己就在示范什么叫数据墨水比。

### 卡 2 · 最佳设计师｜田中一光（几何网格构成）
- **借的机制**：网格上的方、圆、四分之一圆拼抽象主图；信息按"字段/类别/主题/步骤"用小红标签分块。
- **不借的**：他的红黑芥黄专色与米纸底（这次从题材重长）。
- **主角素材**：几何构成的主视觉（用图表图形的几何化替代）。
- **骨架**：严格几何栅格，圆/方作为分区母题。
- **胆量**：把五种画布各压成一个几何标记。
- **form 来自内容**：数据图形天然是几何。
- _（备选，未做完整版）_

### 卡 3 · 现实参照｜Linear / Cursor（暗夜玻璃 bento）
- **借的机制**：bento 网格分块 + 发丝分割线 + 玻璃拟态；单一荧光 accent 只用于"状态/当前步骤"。
- **不借的**：Linear 的紫蓝品牌色与具体 UI。
- **主角素材**：代码 + 运行时控制台（runtime 画布是本站最强的情感点）。
- **骨架**：暗底三栏，画布区是发光玻璃面板，代码高亮 + 变量监视器。
- **胆量**：全站唯一彩色是那抹荧光 accent，且只标记"当前/运行/命中"。
- **form 来自内容**：深夜写代码的终端，是每个学 Python 的人最熟的场景。

### 卡 4 · 现实参照｜The Verge 2022（新粗野主义撞色）
- **借的机制**：2–4px 粗黑描边 + 硬投影（4px 4px 0）+ 卡片 hover 撞色翻转。
- **不借的**：The Verge 的电光紫/品红品牌色。
- **主角素材**：高饱和色块分区，一个语法概念一个色块。
- **骨架**：卡片化分区，粗描边卡片堆叠，步骤用色块进度。
- **胆量**：高饱和撞色 + 近乎无圆角。
- **form 来自内容**：Python 的语法分块（列表/字典/函数）天然适合色块分区。

### 卡 5 · 秒数轮盘 web #13（S=12）｜Glassmorphism Bento
- 与卡 3 同族（暗底玻璃），不做重复，作为卡 3 的加强备选。

### 卡 6 · 秒数轮盘 east #1（S=12）｜吕敬人书艺
- 与卡 1 同源，已并入卡 1（借"版心呼吸 + 朱印"）。
